# One Emoji, One Smile

One emoji, and nothing else: 🫶

Heart Hands — two hands forming a heart. A stranger reads it at first
glance as warm, friendly appreciation: a small, deliberate gesture of
kindness with no words, no irony, no intimacy and no flirtation. It is
chosen rather than default — not the first smiley that comes to mind —
yet instantly readable by anyone, of any age or background.

## Why this emoji

The judge picks the warmer of two emojis. Heart Hands wins on the
brief's own order: it plainly aims to warm a stranger (criterion 1),
it is kind and friendly at first glance with no context needed (2), it
reads the same way universally (3), it feels picked for the moment
rather than default (4), and it works coming from someone unknown —
appreciation, not intimacy, sarcasm or flirtation (5).

## Run

```sh
node main.ts
```

This writes exactly the emoji above to `/output/entry.txt`, with no
trailing newline.

For local checks, point the output elsewhere:

```sh
OUTPUT_PATH=/tmp/entry.txt node main.ts
```
